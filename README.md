Лабораторная работа №2. Классы и объекты в Dart
В данной лабораторной работе мы знакомимся с основами объектно-ориентированного программирования, учимся создавать классы, работать с полями, конструкторами и методами. Пишем консольное ToDo-приложение.

Выполнил: студент группы ИСП-241 Просвиров Дмитрий.

Как запустить:
1. Клонировать репозиторий: `git clone <url>`
2. Перейти в папку: `cd lab2_todo`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

Что изучили:
1. Классы и как их объявлять/создавать.
2. Конструкторы, поля и методы.
3. Вычисляемые свойства, статусы.
4. Добавление и использования пакета Ansicolor.

Ответы на вопросы: 
1. Переменная в функции (локальная) живет только пока выполняется эта функция. Другие функции её не видят.

Поле класса живет всё время, пока существует объект этого класса. К нему имеют доступ все методы внутри класса.

2. Конструктор - это специальный метод, который автоматически вызывается при создании объекта (например, Todo(...)). Он нужен для того, чтобы сразу задать начальные значения полей объекта.

3. Это аннотация-подсказка. Она говорит компилятору: «Я переписываю метод, который уже есть у родителя.

Если убрать: Код всё равно скомпилируется и запустится. Но если сделать опечатку в названии, компилятор промолчит, и случайно создастся новый метод вместо перезаписи старого. Программа будет работать неправильно.

4. Обычное поле: Принадлежит конкретному объекту. Если создать 5 объектов, будет 5 копий этого поля.

Статическое поле: Принадлежит самому классу, а не объектам. Оно общее для всех.

Копий в программе: ровно 1.

5. Нижнее подчёркивание делает поле приватным. В Dart нижнее подчеркивание означает, что доступ к переменной есть только внутри того же файла (библиотеки). Из других файлов обратиться к _counter нельзя.
